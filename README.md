# 📺 واصل (Wassel) — مشاركة الشاشة بين جهازين

تطبيق ويب بسيط لمشاركة الشاشة (أو نافذة أو تبويب) من جهاز لجهاز آخر عبر الإنترنت، مبني باستخدام **WebRTC** للبث المباشر و **Firebase** كوسيط للاتصال، بدون أي سيرفر خاص.

## ✨ المميزات
- مشاركة الشاشة في الوقت الفعلي.
- الاتصال يتم عبر كود من 6 أرقام — بدون تسجيل أو حساب.
- واجهة عربية بسيطة ومتجاوبة مع الجوال.
- مجاني 100% (Firebase Free Tier + GitHub Pages).

## 🚀 طريقة الاستخدام

1. افتح الموقع على الجهازين.
2. **الجهاز اللي بيعرض:** اضغط "أنا الجهاز اللي بيعرض" → وافق على مشاركة الشاشة → سيظهر كود من 6 أرقام.
3. **الجهاز اللي بدو يشوف:** اضغط "أنا الجهاز اللي بدو يشوف" → أدخل الكود → اضغط "اتصال".
4. يبدأ البث مباشرة 🎉

## ⚠️ ملاحظات
- **HTTPS إلزامي:** التطبيق يعمل فقط على الروابط الآمنة (مثل GitHub Pages).
- **الجهاز الناشر يجب أن يكون كمبيوتر** (أو متصفح يدعم مشاركة الشاشة).
- إذا انقطع الاتصال، أعد تحميل الصفحة.
